# Local data inputs

The source files are excluded from version control because their redistribution terms were not established.

- Place the ETF archive at `data/CTA_data.zip`. It should contain `_manifest.csv` and one daily OHLCV file per symbol.

- Place `USO_ohlcv_1d_adjusted.csv` and `UNG_ohlcv_1d_adjusted.csv` in `data/adjusted/`. Each file should contain `ts_event`, OHLC prices, and volume.
